# 中文商店文案

## 名称

Blob 图片顺序下载

## 简短说明

按阅读顺序下载网页 blob 原图，或合并成一个 PDF，每张图片一页，全程本地处理。

## 详细说明

将当前网页中已加载、可见的 blob 图片，按从上到下、同一行从左到右的阅读顺序保存为原图或一个 PDF。

点击插件图标，扫描并查看数量、尺寸及顺序，再选择「按顺序下载」或「合并为 PDF」。每批输出进入浏览器下载目录内的独立子文件夹。

功能：

- 预览图片数量、尺寸和下载顺序。
- 文件依次编号，例如 image_001.png、image_002.jpg。
- 原图下载保留原始图片字节和格式，不强制转成 PNG。
- PDF 按相同顺序每张图片一页，保持宽高比，支持横竖图混排与透明图片。
- PDF 中 JPEG 直接嵌入，其他可解码格式转为 PNG；动图取首帧。
- 图片失败或停止合并时不导出缺页 PDF，并显示原因。
- 自定义文件名前缀、下载子文件夹、最小尺寸、同行容差和提交间隔。
- 区分已保存、失败、保存中及未提交，失败条目可查看原因。
- 关闭弹窗后继续下载或合成 PDF，重开恢复当前会话进度。
- 可停止后续图片提交，已经交给浏览器的下载仍继续。

隐私：

点击插件后才访问所选页面，不要求持续访问所有网站。无广告、分析统计、远程脚本或向开发者上传图片。设置和进度只在本地保存。

范围与限制：

只处理主页面及同源 iframe 内已加载、可见且地址为 blob URL 的图片元素。不自动滚动，不访问跨域或不允许同源访问的沙盒 iframe，不下载普通 HTTP 图片、背景图或视频。单张原图上限 24 MiB；PDF 单图不超过 4000 万像素，整批按原文件与转码后文件大小的较大值累计，上限 256 MiB。请保持来源页面打开。URL 被撤销或浏览器策略限制时会显示失败。

插件界面为简体中文。免费使用，采用 MIT 开源许可证。源代码、中英文说明和反馈入口见 GitHub 项目链接。
